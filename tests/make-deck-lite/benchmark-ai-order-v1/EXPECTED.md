# Expected first-pass deck behavior

This is not a pixel-perfect golden deck. It is the behavior target for the first PowerPoint Copilot output.

## Expected slide logic

A good result is usually 5–7 slides. A six-slide interpretation is:

1. **Opening / conclusion** — rollout has moved from expansion to operating-quality improvement.
2. **Key numbers** — 39 stores, 22.27% correction rate, 5.24% → 5.81%, +0.58pt.
3. **Interpretation of manual intervention** — human correction remains material; distinguish necessary exceptions from unexplained edits.
4. **Association / caution** — r=0.39 is an association signal, not causal proof.
5. **Operating issues** — exception items, shelf plan / Min-Max, weekly ordering, correction-reason logging.
6. **Next actions** — log correction reasons, define exceptions, improve shelf-plan / Min-Max operation.

The exact slide count and wording may differ if the story remains coherent and evidence-grounded.

## Expected visual behavior

- white / warm off-white base
- black primary type and rules
- vermilion red as primary accent
- yellow only as a small signal color
- strong headline typography
- generous whitespace
- at least three different slide silhouettes across the deck
- not more than two consecutive card-grid slides
- important numbers visually dominant but still editable

## Automatic fail conditions

- invented ROI / savings / effect numbers
- claims that r=0.39 proves causality
- unreadable text caused by shrinking
- text or charts visibly overlap the title area
- five or more slides with essentially the same card-grid layout
- ending without a concrete action / decision page
