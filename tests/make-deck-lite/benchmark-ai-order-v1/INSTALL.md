# Install `make-deck-lite` in Copilot for PowerPoint

Current Microsoft guidance supports custom skills in Copilot for PowerPoint.

## UI path

1. Open PowerPoint for Microsoft 365.
2. Open the Copilot pane.
3. Select `+` in the prompt box.
4. Choose **Choose skills**.
5. Scroll to **Manage skills**.
6. Choose **Add skill**.
7. Upload/paste the `make-deck-lite` skill.

The skill folder name and frontmatter `name` should both be `make-deck-lite`, and the folder must contain `SKILL.md`.

After installation, invoke it with:

`@make-deck-lite`

If it does not appear, refresh **Manage skills** and confirm the SKILL.md frontmatter is present.
